How Runguard AI Works

A deep dive into the neural network, data pipeline, and prediction engine.

🧠

Neural Network

Our model is a feedforward neural network built from scratch with NumPy. It uses 12 technical features including OHLCV data, returns, moving averages, and volatility to make predictions.

  • Input Layer: 12 features
  • Hidden Layers: 32 neurons with ReLU activation
  • Output Layer: 1 neuron (predicted price)
  • Loss Function: Mean Squared Error (MSE)
  • Optimizer: Gradient Descent
📊

Feature Engineering

Raw price data is transformed into meaningful features that help the model learn patterns.

  • OHLCV: Open, High, Low, Close, Volume
  • Returns: 1-period, 3-period, 6-period returns
  • Moving Averages: SMA-7, SMA-20
  • Volatility: 7-period volatility
  • Range: High-Low percentage range
🔄

Ensemble Strategy

The model is compared against a simple recent-return baseline on a validation set. A blend weight is selected from validation data, so the final prediction doesn't automatically trust the neural network when it performs worse than the baseline.

⚡

Live Anchoring

Every prediction is anchored to the actual live CoinGecko price captured at the moment of prediction. This ensures the forecast is always based on the most recent market data.

Data Flow

CoinGecko API → Local Cache → Feature Engineering → Model Training → Live Prediction → Result Display
