ABOUT

Runguard AI

A website-first crypto prediction MVP designed around transparent data flow, a NumPy-only neural network, and user-selected prediction horizons.

Data handling

Hourly data is refreshed from CoinGecko's market-chart endpoint and capped at the documented 100-day hourly window. Daily data uses the daily market-chart interval.

Reliability

Downloaded datasets are cached for 24 hours. If the network is unavailable and no cache exists, the development MVP uses deterministic synthetic data so the interface can still be exercised.
