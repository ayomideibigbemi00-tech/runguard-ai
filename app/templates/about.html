How Runguard AI Works

A deep dive into the neural network, data pipeline, and prediction engine.

🧠

Neural Network

Our model is a feedforward neural network built from scratch with NumPy.

  • Input Layer: 12 features
  • Hidden Layers: 32 neurons with ReLU
  • Output Layer: 1 neuron
  • Loss Function: MSE
  • Optimizer: Gradient Descent
📊

Feature Engineering

Raw price data transformed into meaningful features.

  • OHLCV: Open, High, Low, Close, Volume
  • Returns: 1, 3, 6-period returns
  • Moving Averages: SMA-7, SMA-20
  • Volatility: 7-period volatility
  • Range: High-Low percentage
🔄

Ensemble Strategy

Compares neural net against simple baseline and picks the better one on validation.

⚡

Live Anchoring

Predictions anchored to actual live CoinGecko price at prediction time.

Data Flow

CoinGecko API → Local Cache → Feature Engineering → Model Training → Live Prediction → Result Display
