How Runguard is evaluated

Accuracy claims are based on chronological, walk-forward testing. The final test period is held out, and every prediction is produced using only data available before that prediction. Runguard compares the neural network with a simple recent-return baseline, because a model that cannot beat a dumb baseline has not earned the right to sound clever.

Use POST /api/backtest with a coin, interval, and horizon to run a research backtest.
